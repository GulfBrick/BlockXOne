# BlockXOne State Machines (MVP)

## KYC Case
- DRAFT -> SUBMITTED -> APPROVED | REJECTED

## Wallet
- PENDING -> APPROVED | REJECTED

## Offering
- DRAFT -> LIVE -> CLOSED

## Subscription
- REQUESTED -> APPROVED -> PAID -> MINTED
- REQUESTED -> REJECTED
- APPROVED -> CANCELLED

## Whitelist Request
- REQUESTED -> EXECUTING -> CONFIRMED | FAILED

## Token Batch
- CREATED -> EXECUTING -> CONFIRMED | FAILED

## Redemption
- REQUESTED -> APPROVED -> BURN_CONFIRMED -> PAYOUT_SENT -> COMPLETED
- REQUESTED -> REJECTED
