# BlockXOne editorial image set

These images were generated specifically for the BlockXOne public experience with the built-in image generation tool. They share one restrained institutional visual world based on black stone, brushed steel, translucent glass, archival paper, frost white and electric cyan.

## Files

- `hero-operable-assets.webp`: 3840 x 2160 opening image for the connected private-asset operating model
- `issuance-sequence.webp`: 3840 x 2400 control path from terms and approval to transaction and register
- `multi-asset-structures.webp`: 3840 x 2160 material studies for supported instrument structures
- `stewardship.webp`: 3840 x 2160 human review, responsibility and role-separated operation
- `evidence-vault.webp`: 3840 x 2160 durable records, evidence boundaries and recovery
- `multi-asset-structures-portrait.webp`: 3072 x 3840 secondary-page asset-class hero
- `stewardship-portrait.webp`: 3072 x 3840 secondary-page operator and investor hero
- `evidence-vault-portrait.webp`: 3072 x 3840 secondary-page trust and control hero

## Prompt direction

The landscape correction prompts preserved each established composition while requesting precise architectural edges, realistic paper fibres, clean glass boundaries, brushed steel, stone grain, physically plausible shadows, and restrained cyan illumination. The issuance image was reframed for its 16:10 website frame so the complete left-to-right control sequence remains visible.

The portrait prompts recomposed the asset studies, stewardship scene, and evidence archive specifically for a 4:5 secondary-page frame. They did not stretch or crop the landscape images into portrait containers.

All prompts explicitly excluded logos, embedded words, readable text, fake interfaces, coins, token symbols, glowing cubes, hexagon fields, cyberpunk cities, robots, generic handshakes, and watermarks.

The PNG generation masters remain in the Codex generated-images directory. Website copies use high-quality WebP encoding and exact delivery dimensions for responsive optimization by Next.js.
