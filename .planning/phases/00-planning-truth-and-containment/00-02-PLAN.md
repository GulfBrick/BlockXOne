# Plan 00-02: Baseline and Worktree Containment

## Objective

Prove that all selected WIP is recoverable, secrets/generated state are excluded, and active work proceeds from a clean exact baseline without modifying the original reference workspace.

## In scope

- dirty-path inventory and disposition;
- source recovery archive and hash;
- selective reference commit;
- isolated branch/worktree;
- baseline and evidence manifests;
- secret-signature and excluded-path checks.

## Tasks

1. Inventory tracked and untracked changes by category.
2. Create a non-secret, non-generated source snapshot outside the repository.
3. Verify archive hash, required entries and forbidden exclusions.
4. Stage reviewed product/planning paths explicitly; never bulk-stage.
5. Run staged diff and high-confidence secret checks.
6. Commit the selective reference baseline locally.
7. Create clean Phase 0 worktree from the exact commit.
8. Compare commit/worktree identity and record evidence.
9. Scan the complete candidate tree and every commit reachable from candidate HEAD for prohibited artifacts.
10. If history is contaminated, open an incident, remove working-tree copies, block all remote actions and require authorised credential/history handling.

- Required master-plan, planning, public UI and contract files are present in recovery.
- Actual environment files, agent state, executables, logs and `nul` are absent.
- Approved production root contains no prohibited path category in its tree or complete reachable history.
- Clean worktree has no uncommitted state before Phase 0 edits.
- Branch, commit and worktree paths are recorded.
