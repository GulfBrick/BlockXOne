# Phase 7 Plan: Investor Portal MVP

## Objective

Rebuild the investor portal so BlockXOne has a coherent investor-facing product, not a collection of sprint pages.

## Tasks

1. **Create the investor workspace shell**
   - establish a consistent investor home layout
   - move the investor default route to the true investor cockpit
   - unify spacing, hierarchy, banners, and action placement

2. **Rebuild onboarding and qualification pages**
   - refine login and signup for investor-only messaging
   - rebuild qualification and KYC pages around status clarity
   - ensure every investor first-run state has a clear next step

3. **Rebuild the market and asset detail experience**
   - create institutional product cards for opportunities
   - rebuild asset detail around overview, suitability, documents, and action
   - remove leftover generic dashboard patterns

4. **Rebuild portfolio and order visibility**
   - create a real investor home and portfolio summary
   - rebuild orders and redemption progress as timeline-driven screens
   - make wallet prompts contextual rather than global

5. **Verify investor journeys**
   - investor signup
   - investor login
   - session recovery
   - qualification review path
   - browse to asset detail
   - portfolio visibility

## Verification

- `npm run build` in `apps/web`
- investor route walkthroughs from `/investor/login`
- local auth verification against backend API
- responsive checks for key investor pages

## Deliverables

- investor shell
- rebuilt investor home
- rebuilt qualification flow pages
- rebuilt market and portfolio pages
- route and session verification evidence
