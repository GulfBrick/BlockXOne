# Phase 8 Plan: Operator Console MVP

## Objective

Rebuild the operator console so BlockXOne has one coherent internal control plane across admin, compliance, issuer, token operations, and wealth-management workflows.

## Tasks

1. **Unify the operator shell**
   - create one consistent operator navigation and page-header system
   - standardize status, quick actions, and audit framing
   - remove mixed dashboard language

2. **Rebuild operator home pages**
   - admin
   - compliance
   - issuer
   - tokenisation-agent
   - wealth manager
   - transfer-focused ledger surface

3. **Rebuild queue and detail pages**
   - case queue
   - user and role management
   - fund and investor operations
   - token operation flows
   - reports and ledger surfaces

4. **Harden role-based routing and messaging**
   - ensure each operator role lands in the right workspace
   - keep copy and navigation aligned with the actual responsibility of the role

5. **Verify operator journeys**
   - super admin
   - compliance officer
   - issuer fund manager
   - tokenisation agent
   - offering manager
   - transfer agent

## Verification

- `npm run build` in `apps/web`
- operator route walkthroughs from `/operator/login`
- role-based redirect checks
- responsive checks for dashboard and queue layouts

## Deliverables

- operator shell
- rebuilt operator landing pages
- rebuilt queue and action surfaces
- role-journey verification evidence
