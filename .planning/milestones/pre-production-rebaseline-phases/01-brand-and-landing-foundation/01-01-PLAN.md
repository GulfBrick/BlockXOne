# Phase 1 Plan: Brand And Landing Foundation

## Objective

Produce the exact design, content, and route plan for the new BlockXOne public surface so implementation can start without ambiguity.

## Tasks

1. **Lock public information architecture**
   - Define the public route tree for marketing, education, trust, and conversion
   - Remove the mixed-login assumption from the public surface

2. **Define landing page narrative**
   - Write the hero, subhead, and CTA hierarchy
   - Explain tokenization in a way that institutions and investors can both follow
   - Clarify the multi-asset thesis without overpromising launch scope

3. **Define the surface split**
   - Finalize `/investor/login` and `/operator/login`
   - Define what each surface can and cannot expose publicly

4. **Create the BlockXOne design contract**
   - Preserve the existing logo and palette
   - Finalize typography, spacing, iconography, motion, and component rules
   - Define accessibility and responsive requirements

5. **Specify the landing page sections**
   - Hero
   - What tokenization means
   - Supported asset classes
   - Platform workflow
   - Investor experience
   - Operator experience
   - Security and compliance
   - Final CTA

6. **Define copy and visual proof points**
   - Replace vague crypto language with institutional language
   - Remove gimmicky or unverified trust statements
   - Decide which claims require evidence before they can appear publicly

7. **Prepare implementation boundaries for Phase 2**
   - Confirm whether public, investor, and operator will be separate apps or route groups
   - Confirm shared UI package and token strategy
   - Confirm required assets for the public build

## Verification

- Public route tree is written down and reviewable
- Landing-page section order is finalized
- Investor and operator entry paths are separated
- Brand usage rules are explicit
- Phase 2 can start implementation without re-deciding public UX fundamentals

## Deliverables

- finalized public IA
- finalized landing-page brief
- finalized login split
- finalized design-system guardrails for the rebuild
