# Phase 3 Plan 01: Separate Safe Production Auth From Local Developer Shortcuts

## Objective

- **What:** Harden auth mode defaults, verify RBAC enforcement on privileged endpoints, and reconcile seeded-user documentation.
- **Why:** `blockxone` now has a verified runtime shell, so the next production risk is auth behavior leaking dev shortcuts into production assumptions.
- **Output:** Evidence-backed auth defaults and permission checks that preserve local usability without weakening production posture.
